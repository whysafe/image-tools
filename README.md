# imgtools

Пакетная обработка изображений из командной строки для сайтов и маркетплейсов: уменьшение, конвертация в WebP, квадратные превью, водяной знак и удаление EXIF. Работает параллельно на всех ядрах процессора.

## Возможности

- `resize`: уменьшение по длинной стороне с сохранением пропорций
- `webp`: конвертация в WebP с заданным качеством
- `thumbs`: квадратные (или любого размера) превью в JPEG с обрезкой по центру, чуть выше середины
- `mark`: текстовый водяной знак в одной из 9 позиций, с тенью, прозрачностью и своим шрифтом
- `strip`: удаление метаданных EXIF (геопозиция, модель телефона)
- Обрабатывает один файл или папку целиком, включая вложенные папки (структура сохраняется)
- Учитывает поворот из EXIF, поэтому фото с телефона не выходят повёрнутыми
- PNG с прозрачностью при сохранении в JPEG получает белый фон вместо чёрного
- Битый файл попадает в отчёт и пропускается, остальная пачка обрабатывается
- Выводит размер до и после для каждого файла и общую экономию

## Стек

Python 3.10+, Pillow, `concurrent.futures.ProcessPoolExecutor`, pytest.

## Как запустить

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python imgtools.py resize photos/ --max 1600 --out out/
python imgtools.py webp   photos/ --quality 82
python imgtools.py thumbs photos/ --size 400x400
python imgtools.py mark   photos/ --text "© Studio" --pos br --opacity 0.6
python imgtools.py strip  photos/
python -m pytest -v
```

Общие аргументы для всех команд:

| Аргумент | Что делает |
|---|---|
| `src` | файл или папка с изображениями (jpg, jpeg, png, webp, bmp, tiff) |
| `--out` | папка для результата, по умолчанию `out` |
| `--quality` | качество JPEG и WebP, по умолчанию 85 |

Аргументы отдельных команд:

| Команда | Аргумент | По умолчанию |
|---|---|---|
| `resize` | `--max` | 1600 |
| `thumbs` | `--size ШxВ` | 400x400 |
| `mark` | `--text` (обязательно), `--pos` (tl, tc, tr, ml, mc, mr, bl, bc, br), `--opacity`, `--font путь.ttf` | br, 0.7, DejaVuSans |

Скрипт возвращает код 1, если были ошибки, что удобно в CI и shell-скриптах. Тесты запускаются в GitHub Actions (`.github/workflows/tests.yml`) на Python 3.11 и 3.12.

## Как это устроено

- Каждая команда это функция `img -> img` в словаре `ACTIONS`; общая функция `process` открывает файл, применяет действие и сохраняет результат.
- Файлы раздаются процессам через `ProcessPoolExecutor.map`, ошибка внутри файла возвращается как результат, а не роняет пул.
- `ImageOps.exif_transpose` применяет поворот к пикселям до любой обработки.
- JPEG сохраняется прогрессивным с `optimize=True`; при сохранении в JPEG прозрачные изображения накладываются на белый фон по альфа-каналу.
- Размер шрифта водяного знака зависит от ширины картинки, если шрифт не найден, используется встроенный шрифт Pillow.
- `strip` пересобирает изображение из пикселей, поэтому в результат не попадает ни один блок метаданных; палитра и прозрачность у картинок в режиме `P` переносятся.
